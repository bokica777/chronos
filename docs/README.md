# Dokumentacija

Ovaj folder predstavlja centralno mesto za dokumentaciju projekta i diplomskog rada.

## Organizacija

- `architecture/` — kontekst sistema, komponente, komunikacija i deployment prikazi
- `api/` — OpenAPI specifikacije i opis javnih ugovora
- `decisions/` — Architecture Decision Records (ADR)
- `database/` — modeli podataka, vlasništvo nad podacima i migracije
- `deployment/` — postupci build-a, promocije, rollback-a i oporavka
- `testing/` — plan funkcionalnog, load, rollout i failure testiranja

Dokumentaciju menjati zajedno sa kodom kada se promeni ugovor, arhitektura ili
operativna procedura.
