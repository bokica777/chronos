# Podaci i migracije

Planirano vlasništvo nad podacima:

- Auth: korisnici, identiteti i uloge
- Provider: pružaoci, usluge i raspoloživost
- Booking: rezervacije i istorija statusa
- Payment: transakcije i statusi plaćanja
- Notification: evidencija obaveštenja

Svaki servis samostalno upravlja svojim migracijama. Konačni ER modeli i pravila
konzistentnosti biće dokumentovani pre implementacije.
