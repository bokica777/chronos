# Architecture Decision Records

ADR dokumenti beleže važnu odluku, razmatrane alternative i posledice odluke.

Predložene prve odluke:

1. izbor domena i granica mikroservisa;
2. ASP.NET Core za glavne servise i Spring Boot za Notification servis;
3. RabbitMQ kao message broker;
4. canary rollout kroz Argo Rollouts;
5. lokalni kind klaster i izbor cloud okruženja za završni demo.
