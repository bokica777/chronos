# API ugovori

Ovde će se nalaziti OpenAPI specifikacije po servisu. Ugovore treba definisati pre
implementacije poslovne logike kako bi frontend, gateway i servisi mogli nezavisno da
se razvijaju.

Planirani fajlovi:

- `auth.openapi.yaml`
- `provider.openapi.yaml`
- `booking.openapi.yaml`
- `payment.openapi.yaml`
