# Chronos frontend

React + TypeScript web aplikacija zasnovana na Vite-u.

Planirane celine:

- autentifikacija;
- pretraga pružalaca i usluga;
- pregled slobodnih termina;
- kreiranje i otkazivanje rezervacije;
- testno plaćanje;
- pregled korisničkih rezervacija.

Za razvoj će se koristiti promenljiva `VITE_API_BASE_URL` koja pokazuje na API
Gateway.
